# Java Day 31 - Count Occurrences in an Array

This Java program counts how many times a specific number appears in an array.

## Example

Array:
```text
10, 20, 10, 30, 10, 40
```

Search number: `10`

Output:
```text
Number: 10
Occurrences: 3
```

## Concepts Used

- Arrays
- `for` loop
- `if` statement
- Comparison operator `==`
- Counter variable
- Increment operator `++`

## How It Works

The program checks every element in the array. Whenever an element matches the search number, the counter increases by one. Finally, the program displays the total number of occurrences.

## What I Learned

I learned how to count the occurrences of a specific number in a Java array using a loop and a counter.
